## Running a Project in Eclipse

1. Open Eclipse.
2. Select **File → Import**.
3. Choose **General → Existing Projects into Workspace**.
4. Select the project folder.
5. Click **Finish**.
6. Open the main Java class and select **Run As → Java Application**.
